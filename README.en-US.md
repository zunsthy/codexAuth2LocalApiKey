# codex-auth-to-local-api-key

Convert a ChatGPT/Codex subscription authenticated through the Codex CLI into a local endpoint compatible with the OpenAI Responses API. This is not an OpenAI Platform API key. Do not expose this service to the public internet.

## Usage

Node.js 24+ and the Codex CLI are required.

[Optional] Configure the Codex CLI to store credentials in a file by adding the following to `~/.codex/config.toml`:

```toml
cli_auth_credentials_store = "file"
```

Install the dependencies and sign in:

```bash
npm install
codex login
```

Start the service:

```bash
node index.js \
  --api-key sk-local-only-0000 \
  --model gpt-5.6-sol \
  --proxy-url http://127.0.0.1:7890
```

You can also run `npm start --` followed by the same arguments. By default, the service listens at `http://127.0.0.1:10680/v1`.

### Example request

```bash
curl http://127.0.0.1:10680/v1/responses \
  -H 'Authorization: Bearer sk-local-only-0000' \
  -H 'Content-Type: application/json' \
  -d '{"model":"gpt-5.6-sol","input":"Reply with: ok","stream":false}'
```

Custom provider configuration for other agents:

```text
Base URL: http://127.0.0.1:10680/v1
API protocol: openai-responses
API key: sk-local-only-0000
Model: gpt-5.6-sol
```

## Common options

- `--api-key KEY`: Local bearer key; required by default
- `--unsafe-no-auth`: Explicitly disable local authentication; use only in a trusted local environment
- `--auth-file PATH`: Path to the Codex `auth.json` file
- `--proxy-url URL`: `env`, `direct`, or an HTTP(S) proxy URL
- `--upstream-timeout-ms MS`: Overall upstream timeout; defaults to 300000 ms
- `--debug`: Log key processing steps without logging tokens or request bodies
- `--help`: Show all available options

`POST /v1/responses` only accepts `Content-Type: application/json`. If the client disconnects, the upstream request is canceled. Size limits apply to non-streaming SSE responses and upstream error bodies.
